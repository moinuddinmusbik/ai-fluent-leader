# Model Replacement Test

A practical exercise to run before an AI vendor renewal: determine whether the work you have already tuned — prompts, fine-tunes, retrieval pipelines, evaluation sets — can move to a cheaper model without starting from scratch.

**The test reveals:**
- If yes → you have genuine model portability, and a cheaper competitor is a real option. Negotiate accordingly.
- If no → your real switching cost is far higher than the per-token pricing delta. Factor this into the renewal decision.

The result also classifies your AI differentiation: portable workflows are potentially a moat (built skill); locked workflows can be either a trap (accidental dependency) or a defensible moat (deliberate fine-tuning on proprietary data).
